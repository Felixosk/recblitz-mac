What's new

Version 3.0 is the biggest update so far. Every window was rebuilt.

RecBlitz 3.0

2026-11-21

A new look, all the way through.

Panel, settings and banner are made of Liquid Glass, the same material as macOS 26. Each window has a round close button on its corner. One accent colour, blue.

Light, dark or system.

Settings → General → Appearance. The glass can be set to Normal or Clearer for busy wallpapers.

Cleaner settings.

Four labelled tabs: General, Transcript, Screen, Drive. Language, microphone list and the Mic, System and Webcam switches now live only in the panel, so nothing is set in two places.

New result banner.

A glass capsule in the same colour as the other windows, with a round close button.

Calmer controls.

The selection bars match MeetingBlitz, and no two buttons touch each other.

  • 2.1 2026-10-05 · Audio only can record system sound. Mic and System are two switches in every mode.
  • 2.0 2026-09-26 · First public release.
