Setup

Two minutes for the app. Ten more if you want a Google Doc and a Drive link.

DownloadBuild it yourselfPermissionsGoogle DriveHelp

Option A: download the app

  1. Get RecBlitz.zip from the latest release and unzip it.
  2. Move RecBlitz.app into your Applications folder.
  3. Run this once in Terminal, then open the app normally:
xattr -dr com.apple.quarantine /Applications/RecBlitz.app
The app is signed with a self-made certificate, not a paid Apple developer account, so macOS quarantines it. The command tells macOS you vouch for it yourself. Only run it on software you trust. Without it: double-click, click Done, then System Settings → Privacy & Security → Open Anyway.

Where is it? The app has no window and no Dock icon. Look for a small waveform at the top right of your menu bar.

Option B: build it yourself

No Gatekeeper warning at all, because software you compile yourself is not quarantined.

git clone https://github.com/Felixosk/recblitz-mac.git
cd recblitz-mac
./build.sh && open dist/RecBlitz.app

Missing Command Line Tools? Install them once with xcode-select --install, then build again.

Permissions

  • Microphone, asked on the first recording.
  • Screen recording, asked on the first screencast, and on the first Audio only recording with System on, because macOS delivers system sound through that permission. Allow it under System Settings → Privacy & Security → Screen & System Audio Recording, then restart RecBlitz.
  • Camera, only for the webcam bubble.

Transcription needs macOS 26. The first run of a language downloads Apple's speech model once, about 10 seconds. On macOS 14 and 15 RecBlitz falls back to mlx-whisper (pip3 install mlx-whisper, Apple Silicon).

Google Drive (optional)

  1. brew install rclone, then rclone config and create a Google Drive remote, for example named gdrive.
  2. In RecBlitz: Settings → Drive, switch it on, enter the remote (gdrive:) and paste the link of the Drive folder for your docs. Videos can go to their own folder.
  3. Record something. The banner shows Google Doc ready, or for a screencast Video ready · link copied.

Sharing uses rclone link, which sets the file to "anyone with the link". Turn off Share video if you want links that only you can open.

If something is off

The menu bar icon is missing

If the menu bar is full, macOS hides icons without a word. ⌥⌘R still starts a recording.

No Google Doc appears

Check Settings → Drive: the green line means rclone was found. Then run rclone lsd gdrive: in Terminal. If that asks you to log in, run rclone config reconnect gdrive:.

Where is my data?

Recordings: ~/Library/Application Support/RecBlitz/recordings/. Settings: config.json in the same folder. Logs: logs/pipeline.log. Nothing is sent anywhere unless you switch on Drive or Summary.
